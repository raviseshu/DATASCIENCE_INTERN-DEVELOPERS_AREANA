# Week 7: Statistical Business Analysis

## Project Overview

This project performs a **statistical analysis of sales and customer behavior**, using:
- `business_data.csv` (sales data)
- `customer_churn.csv` (customer churn metrics)

The analysis covers:
- Descriptive statistics (mean, median, mode, std)
- Distribution analysis (histograms, KDE plots)
- Correlation analysis and heatmaps
- Hypothesis testing (t-tests, chi-square, ANOVA-style group comparison)
- Confidence intervals for key metrics
- Simple regression analysis (sales vs marketing, tenure vs charges)

## Files

- `statistical_analysis.ipynb` – Main analysis notebook
- `statistical_analysis.py` – Script version (optional)
- `business_data.csv` – Sales data (from sales_data-2.csv)
- `customer_churn.csv` – Customer data
- `STATISTICAL_REPORT.md` – Statistical analysis report (export as PDF)
- `hypothesis_tests_results.txt` – Text summary of hypothesis tests
- `requirements.txt` – Dependencies
- `visualizations/` – Saved charts for documentation
- `tests/` – Basic validation tests
